# Knowledge, Context and Agentic Engineering for Knowledge Work

Master corpus and workshop platform for the teaching line *Knowledge, Context and Agentic Engineering*. The master slide deck and master script cover the full material, from LLM fundamentals through prompt, context, knowledge and agentic engineering to Promptotyping and verification. Each workshop or course derives a documented profile from this corpus, specialised for its audience, domain and duration.

The platform (GitHub Pages, in preparation) presents the master deck and the register of all workshop instances with date, title, venue, audience and variant focus: https://digitalhumanitiescraft.github.io/knowledge-context-agentic-engineering/

## Structure

| Path | Content |
| --- | --- |
| `knowledge/` | Project knowledge base (Promptotyping documents): charter, specification, term matrix, design, governance, journal, plan |
| `skriptum/` | Master script (German) and derived lecture notes (English), versioned here |
| `slides/` | Master slide texts and speaker notes; the visual decks live in Google Slides and are linked |
| `workshops/` | One profile per workshop instance: audience, prerequisites, selection from the master, deviations, slide exports |
| `docs/` | The platform (static site, GitHub Pages) |
| `assets/` | Visualisations; no facsimiles (image rights remain with the source projects) |
