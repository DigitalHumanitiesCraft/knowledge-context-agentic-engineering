# Superseded Platform Prototypes

These files preserve earlier HTML design studies for the teaching platform. They are non-canonical historical prototypes and do not belong to the public site.

The current design contract is `knowledge/design.md`; the current page and content contract is `knowledge/specification.md`. Individual prototypes may therefore contain old navigation, typography, dynamic-rendering assumptions, placeholder copy, external links or interface structures that the maintained platform no longer uses.

The shared chrome file is a historical copy fragment rather than a standalone page. Its relative paths document its former insertion context and are intentionally not maintained as working links.
