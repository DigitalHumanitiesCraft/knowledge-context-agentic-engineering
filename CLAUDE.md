# CLAUDE.md

Master corpus and workshop platform for *Knowledge, Context and Agentic Engineering for Knowledge Work*. Read `knowledge/INDEX.md` first; the knowledge base in `knowledge/` is the working context for every substantial task.

## Rules

- The repo is the canonical home of the master texts (`script/`, `slides/`). The author's vault holds project coordination and the thematic knowledge base; Google Slides and Google Docs are presentation surfaces, never canonical text state.
- All repository files are English, including file and folder names. The master script content is bilingual: German is the source language; English versions arise by agent translation and count as canonical only after operator review.
- `knowledge/drafts/` holds agent-written decision preparation; drafts are proposals, never canonical.
- Before any UI work in `docs/`, read `knowledge/design.md` and follow it. Frontend code follows the no-build regime: static HTML, CSS and vanilla JS, no build step, no external CDNs beyond Google Fonts.
- Term decisions, design approvals, publication steps, git tags, rights questions and everything listed in `knowledge/governance.md` as operator-gated go to the operator; prepare, do not decide.
- No facsimiles and no third-party personal data in this repo. Image rights for Hersch and Zweig material remain with the source projects; link, do not copy.
- Record decisions and session outcomes in `knowledge/journal.md`; keep `knowledge/plan.md` current when steps complete.
