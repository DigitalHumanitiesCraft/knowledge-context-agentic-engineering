Set up your working environment

This tutorial prepares a reusable environment for work with language models, local files, Python and an AI harness. It is independent of any project or event. Start with the browser path and continue until the tools required for your work have passed their checks.

Last verified 25 August 2026

Use a practice folder that contains no confidential or irreplaceable files. Each section ends with an observable result.

On this page Choose a path· Model access· Editor and terminal· Python· Local server· AI harness· System check· Troubleshooting

Choose your setup path

The paths build on one another. Complete only the highest path your work requires.

  1. L1

    Browser workspace

    A model account and a current browser. No local installation.

  2. L2

    Local working environment

    Level 1 plus Visual Studio Code, a terminal, Python and a local web server.

  3. L3

    AI harness

    Level 2 plus Claude Code or another harness that can operate on a controlled working folder.

Level 1

Set up model access

Open the language-model service you intend to use and sign in. A browser-based account is sufficient for Level 1. An AI harness may require a compatible paid plan, API key or organisation account; check the access conditions of the selected harness before installing it.

  1. Open the service in the browser and complete sign-in, including any required multi-factor authentication.
  2. Start a new conversation and ask the model to return the exact text browser ready.
  3. Confirm that you know where downloaded files are stored and how to attach a local file.

The path is complete when the model answers in a new conversation and you can attach a non-sensitive test file.

Level 2

Install the editor and open a terminal

Visual Studio Code provides one surface for files, code and the terminal. The terminal runs commands in the currently opened folder and shows the output needed for diagnosis.

  1. Download Visual Studio Code from code.visualstudio.com and install it.
  2. Create a folder named ai-workspace in a location you can find again.
  3. Open that folder with File, then Open Folder.
  4. Open Terminal, then New Terminal. Its prompt should point to ai-workspace.
  5. Create readme.md, write one sentence, save it and confirm that the file appears in the Explorer.

The editor is ready when the integrated terminal and the saved file refer to the same folder.

Level 2

Install and verify Python

Python runs scripts and provides the local web server used in the next section.

  1. Install Python from python.org/downloads. On Windows, enable Add Python to PATH if the installer offers it.
  2. Install the Microsoft Python extension in the Visual Studio Code Extensions view.
  3. Run the version check. On macOS or Linux, use python3 if python is unavailable.
    python --version
  4. Create check.py with the following line and run it.
    print("python ready")
    python check.py

Python is ready when the terminal prints a version number and then python ready.

Level 2

Start a local web server

Browsers restrict pages opened directly from the file system. A local server gives a prototype a normal web address and allows it to load local data files.

  1. Create index.html in ai-workspace and add <h1>Local server ready</h1>.
  2. Run the server from the integrated terminal.
    python -m http.server 8000
  3. Open http://localhost:8000 in the browser.
  4. Confirm that the heading appears, then return to the terminal and stop the server with Ctrl+C.

The local environment is ready when the browser displays the file through localhost.

Level 3

Install and constrain an AI harness

An AI harness connects a language model with local files, tools and executable commands. This tutorial uses Claude Code as the concrete implementation. The same safety boundary applies to comparable harnesses: start them only inside a folder whose contents they may inspect and change.

  1. Confirm that your Claude account or API access includes Claude Code.
  2. Open the terminal in ai-workspace and run one official installation command.
    macOS, Linux or Windows Subsystem for Linux
    curl -fsSL https://claude.ai/install.sh | bash
    Windows PowerShell
    irm https://claude.ai/install.ps1 | iex
    macOS with Homebrew
    brew install --cask claude-code
    Windows with WinGet
    winget install Anthropic.ClaudeCode
  3. Verify the installation and run the read-only diagnostic.
    claude --version
    claude doctor
  4. Start claude, complete authentication in the browser and return to the terminal.
  5. Ask the harness to list the files in the current folder without changing them. The answer should name readme.md, check.py and index.html.
  6. Exit the session. Do not test first-run file changes in a folder containing personal, organisational or research data.

Use the official Claude Code setup documentation when installation commands or account conditions change.

Run the complete system check

  1. The browser account opens a new conversation and accepts a test attachment.
  2. Visual Studio Code opens ai-workspace and its terminal points to that folder.
  3. python --version returns a version and python check.py prints the expected text.
  4. http://localhost:8000 displays index.html while the local server is running.
  5. For Level 3, claude --version and claude doctor complete, and the harness can read the practice folder.

Troubleshoot from evidence

  1. Copy the complete command and error message as text.
  2. Record the operating system, terminal and current folder.
  3. Check the official installation page of the failing tool.
  4. Ask a language model to explain the error and propose one reversible diagnostic command.
  5. Change one condition at a time and rerun the same check.
