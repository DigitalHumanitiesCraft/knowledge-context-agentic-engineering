VetMed Winter School

Generative AI, research data and agentic workflows

Event University of Veterinary Medicine Vienna Language German Licence CC BY 4.0

Abstract

The five-day block course develops a complete working environment for generative AI, data work and agentic processes. Participants progress from model foundations and prompting to local code execution, structured knowledge, data transformation and controlled agent workflows. One application project from the participant’s own working area connects the exercises across the week.

Outline

  1. Day oneModel foundations, limits and working environment
  2. Day twoPrompt and context engineering with local code
  3. Day threeData formats, transformation and representation
  4. Day fourAI harnesses, local models and controlled agent work
  5. Day fiveApplication project, presentation and transfer

Learning objectives

  • Choose an appropriate model and working environment for a bounded task.
  • Prepare and transform structured and unstructured data with inspectable checks.
  • Represent project knowledge in a form usable by people and AI systems.
  • Develop and assess an application project through a controlled agent workflow.
