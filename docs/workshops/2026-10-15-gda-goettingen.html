Abstract

This hybrid half-day workshop examines how coding agents can support data preparation, migration and the maintenance of research interfaces. Case studies from archival data, OCR-to-TEI processing and static publication show how machine-readable project knowledge connects data and software. Participants then prepare a small sample of their own material, define acceptance criteria and inspect the resulting transformation.

Learning objectives

  • Identify tasks suited to deterministic scripts and tasks suited to model processing.
  • Describe project knowledge required for a maintainable transformation.
  • Formulate a bounded commission with acceptance criteria.
  • Inspect the resulting data and interface changes against the source material.
