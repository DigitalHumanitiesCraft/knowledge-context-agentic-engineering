Knowledge, Context and Agentic Engineering for Knowledge Work

This teaching line for researchers and professionals examines how Large Language Models (LLMs) operate inside Working environments that connect an LLM with project context, files, tools and controlled actions. for computer-based, data-driven knowledge work. Workshops select from its five modules and adapt them to a field, task and teaching language.
