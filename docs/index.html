Knowledge, Context and Agentic Engineering for Knowledge Work

This teaching line examines how Models trained on extensive text corpora to process instructions and generate context-dependent language. operate inside Working environments that connect a language model with project context, files, tools and controlled actions. for computer-based, data-driven knowledge work. Its five modules connect model foundations with The deliberate formulation of instructions for a specific model, task and intended output., Maintaining explicit project knowledge and assembling the information a model needs for the current task., Organising extended work across tool use, intermediate results, permissions, feedback and human review., and Examining technical limits and social consequences, and defining responsibility and rules for use.. The shared Full Slide Deck, two Full Lecture Notes language versions and an ordered Video Playlist carry the material; each workshop selects from these sources and adapts them to a defined field, task and teaching language.

The preparation tutorial shows you how to set up everything you need to take part in a workshop.
