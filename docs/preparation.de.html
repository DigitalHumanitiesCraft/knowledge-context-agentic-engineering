Arbeitsumgebung einrichten

Dieses Tutorial richtet eine wiederverwendbare Umgebung für die Arbeit mit Sprachmodellen, lokalen Dateien, Python und einem AI Harness ein. Es ist unabhängig von einem bestimmten Projekt oder einer Veranstaltung. Beginne mit dem Browser-Pfad und arbeite bis zu den Werkzeugen weiter, die du für deine Arbeit benötigst.

Zuletzt geprüft am 25. August 2026

Verwende einen Übungsordner ohne vertrauliche oder unersetzliche Dateien. Jeder Abschnitt endet mit einem beobachtbaren Prüfergebnis.

Auf dieser Seite Pfad wählen· Modellzugang· Editor und Terminal· Python· Lokaler Server· AI Harness· Systemcheck· Fehlerbehebung

Einrichtungspfad wählen

Die Pfade bauen aufeinander auf. Bearbeite nur den höchsten Pfad, den deine Arbeit benötigt.

  1. L1

    Browser-Arbeitsplatz

    Ein Modellkonto und ein aktueller Browser. Keine lokale Installation.

  2. L2

    Lokale Arbeitsumgebung

    Stufe 1 sowie Visual Studio Code, Terminal, Python und ein lokaler Webserver.

  3. L3

    AI Harness

    Stufe 2 sowie Claude Code oder ein anderes Harness, das in einem kontrollierten Arbeitsordner agiert.

Stufe 1

Modellzugang einrichten

Öffne den gewünschten Sprachmodelldienst und melde dich an. Für Stufe 1 genügt ein browserbasiertes Konto. Ein AI Harness kann einen geeigneten Bezahlplan, einen API-Schlüssel oder ein Organisationskonto voraussetzen. Prüfe die Zugangsbedingungen des gewählten Harness vor der Installation.

  1. Öffne den Dienst im Browser und schließe die Anmeldung einschließlich einer erforderlichen Mehrfaktor-Authentifizierung ab.
  2. Beginne eine neue Unterhaltung und bitte das Modell um die exakte Ausgabe browser ready.
  3. Prüfe, wo Downloads gespeichert werden und wie du eine lokale Datei anhängst.

Der Pfad ist abgeschlossen, wenn das Modell in einer neuen Unterhaltung antwortet und du eine unvertrauliche Testdatei anhängen kannst.

Stufe 2

Editor installieren und Terminal öffnen

Visual Studio Code bündelt Dateien, Code und Terminal in einer Oberfläche. Das Terminal führt Befehle im geöffneten Ordner aus und zeigt die für die Diagnose erforderlichen Ausgaben.

  1. Lade Visual Studio Code von code.visualstudio.com herunter und installiere es.
  2. Lege an einem wiederauffindbaren Ort einen Ordner namens ai-workspace an.
  3. Öffne diesen Ordner über Datei und anschließend Ordner öffnen.
  4. Öffne über Terminal und anschließend Neues Terminal das integrierte Terminal. Die Eingabezeile soll auf ai-workspace verweisen.
  5. Lege readme.md an, schreibe einen Satz, speichere die Datei und prüfe, ob sie im Explorer erscheint.

Der Editor ist eingerichtet, wenn das integrierte Terminal und die gespeicherte Datei auf denselben Ordner verweisen.

Stufe 2

Python installieren und prüfen

Python führt Skripte aus und stellt den lokalen Webserver für den nächsten Abschnitt bereit.

  1. Installiere Python von python.org/downloads. Aktiviere unter Windows die Option Add Python to PATH, sofern sie angeboten wird.
  2. Installiere in der Erweiterungsansicht von Visual Studio Code die Microsoft-Erweiterung Python.
  3. Führe die Versionsprüfung aus. Verwende unter macOS oder Linux python3, falls python nicht verfügbar ist.
    python --version
  4. Lege check.py mit der folgenden Zeile an und führe die Datei aus.
    print("python ready")
    python check.py

Python ist eingerichtet, wenn das Terminal eine Versionsnummer und anschließend python ready ausgibt.

Stufe 2

Lokalen Webserver starten

Browser beschränken Seiten, die direkt aus dem Dateisystem geöffnet werden. Ein lokaler Server gibt einem Prototyp eine reguläre Webadresse und erlaubt das Laden lokaler Datendateien.

  1. Lege index.html in ai-workspace an und füge <h1>Local server ready</h1> ein.
  2. Starte den Server im integrierten Terminal.
    python -m http.server 8000
  3. Öffne http://localhost:8000 im Browser.
  4. Prüfe, ob die Überschrift erscheint. Kehre zum Terminal zurück und beende den Server mit Ctrl+C.

Die lokale Umgebung ist eingerichtet, wenn der Browser die Datei über localhost anzeigt.

Stufe 3

AI Harness installieren und begrenzen

Ein AI Harness verbindet ein Sprachmodell mit lokalen Dateien, Werkzeugen und ausführbaren Befehlen. Dieses Tutorial verwendet Claude Code als konkrete Umsetzung. Für vergleichbare Harnesses gilt dieselbe Sicherheitsgrenze: Starte sie nur in einem Ordner, dessen Inhalte sie einsehen und verändern dürfen.

  1. Prüfe, ob dein Claude-Konto oder API-Zugang Claude Code umfasst.
  2. Öffne das Terminal in ai-workspace und führe einen offiziellen Installationsbefehl aus.
    macOS, Linux oder Windows Subsystem for Linux
    curl -fsSL https://claude.ai/install.sh | bash
    Windows PowerShell
    irm https://claude.ai/install.ps1 | iex
    macOS mit Homebrew
    brew install --cask claude-code
    Windows mit WinGet
    winget install Anthropic.ClaudeCode
  3. Prüfe die Installation und führe die nur lesende Diagnose aus.
    claude --version
    claude doctor
  4. Starte claude, schließe die Anmeldung im Browser ab und kehre zum Terminal zurück.
  5. Bitte das Harness, die Dateien im aktuellen Ordner aufzulisten, ohne sie zu verändern. Die Antwort soll readme.md, check.py und index.html nennen.
  6. Beende die Sitzung. Erprobe Dateiänderungen beim ersten Start ausschließlich im unvertraulichen Übungsordner.

Prüfe bei geänderten Installationsbefehlen oder Zugangsbedingungen die offizielle Einrichtungsdokumentation für Claude Code.

Vollständigen Systemcheck durchführen

  1. Das Browserkonto öffnet eine neue Unterhaltung und nimmt einen Testanhang an.
  2. Visual Studio Code öffnet ai-workspace, und das Terminal verweist auf diesen Ordner.
  3. python --version gibt eine Version aus, und python check.py zeigt den erwarteten Text.
  4. http://localhost:8000 zeigt bei laufendem Server die Datei index.html.
  5. Für Stufe 3 laufen claude --version und claude doctor durch, und das Harness kann den Übungsordner lesen.

Fehler anhand von Evidenz untersuchen

  1. Kopiere den vollständigen Befehl und die vollständige Fehlermeldung als Text.
  2. Notiere Betriebssystem, Terminal und aktuellen Ordner.
  3. Prüfe die offizielle Installationsseite des betroffenen Werkzeugs.
  4. Bitte ein Sprachmodell um eine Erklärung des Fehlers und einen reversiblen Diagnosebefehl.
  5. Ändere jeweils nur eine Bedingung und führe denselben Test erneut aus.
