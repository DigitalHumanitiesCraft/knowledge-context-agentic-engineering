Stufe 3

Claude Code

Claude Code ist ein terminalbasiertes AI Harness. Es kann Dateien im geöffneten Arbeitsordner lesen und bearbeiten, Befehle ausführen und Zwischenergebnisse prüfen. Für die agentischen Workshops wird ein Konto mit Zugriff auf Claude Code benötigt.

  1. Öffne unter Windows PowerShell und unter macOS oder Linux die Terminal-App.
  2. Führe den Installationsbefehl für dein System aus.
    macOS, Linux oder Windows Subsystem for Linux
    curl -fsSL https://claude.ai/install.sh | bash
    Windows PowerShell
    irm https://claude.ai/install.ps1 | iex
    macOS mit Homebrew
    brew install --cask claude-code
    Windows mit WinGet
    winget install Anthropic.ClaudeCode
  3. Unter Windows wird zusätzlich Git for Windows benötigt.
  4. Lege einen leeren Workshop-Ordner an und öffne ihn im Terminal.
  5. Starte Claude Code mit claude und schließe die Anmeldung im Browser ab.
  6. Bitte Claude Code, die Dateien des geöffneten Ordners aufzulisten. Damit sind Installation, Anmeldung und Dateizugriff geprüft.

Die aktuellen Installationshinweise stehen in der offiziellen Dokumentation.

Stufen 2 und 3

Visual Studio Code

Visual Studio Code ist der Editor für Dateien, Code und das integrierte Terminal.

  1. Lade den Editor von code.visualstudio.com und installiere ihn.
  2. Installiere in der Erweiterungsansicht die von Microsoft veröffentlichten Erweiterungen „Python“ und „Pylance“.
  3. Installiere für Workshops mit einer lokalen Webseite zusätzlich „Live Server“.
  4. Öffne über „Terminal“ und „New Terminal“ das integrierte Terminal.

Stufen 2 und 3

Python

Python führt die im Workshop erzeugten Skripte aus. Programmierkenntnisse sind dafür keine Voraussetzung.

  1. Installiere Python über den Microsoft Store oder über python.org.
  2. Aktiviere bei einer Windows-Installation von python.org die Option „Add Python to PATH“.
  3. Prüfe die Installation im Terminal. 
    python --version
  4. Wähle in Visual Studio Code über „Python: Select Interpreter“ die installierte Python-Version.
  5. Lege eine Datei test.py mit einer Zeile an und führe sie aus. 
    print("ready")
    python test.py

Konten und Zugänge

Modellzugang

Für browserbasierte Einheiten genügt der in der Workshopseite angegebene Modellzugang. Agentische Einheiten mit Claude Code erfordern ein Konto mit einem geeigneten Abonnement oder einen eingerichteten API-Zugang.

Google-Konto

Einige Materialien liegen in Google Drive oder Google Colab. Öffne die auf der Workshopseite verlinkten Materialien vorab und prüfe den Zugriff.

GitHub-Konto

Öffentliche Workshop-Repositories können ohne Konto gelesen und heruntergeladen werden. Ein Konto wird benötigt, wenn eigene Ergebnisse in einem Repository versioniert werden.

Alle Stufen

Systemcheck

  1. python --version gibt eine Versionsnummer aus.
  2. Visual Studio Code startet und zeigt die Python-Erweiterung als installiert.
  3. test.py wurde einmal erfolgreich ausgeführt.
  4. Die Anmeldung beim verwendeten Modell funktioniert im Browser.
  5. Bei Stufe 3 startet claude im Workshop-Ordner.
  6. Die auf der Workshopseite verlinkten Materialien sind erreichbar.

Fehlerbehebung

  1. Lies die vollständige Fehlermeldung und sichere sie als Text.
  2. Gib die Fehlermeldung zusammen mit dem ausgeführten Befehl an ein Sprachmodell weiter.
  3. Bleibt der Fehler bestehen, sende Fehlermeldung, Betriebssystem und Screenshot an den Workshopkontakt.
