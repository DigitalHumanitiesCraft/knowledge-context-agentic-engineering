Script Placeholder excerpt

The full script lives as a Google Doc. The excerpt below demonstrates the language switch; both texts are written for this draft.

English

A large language model does not look facts up in a store. It continues a text under the conditions its context sets. Everything the LLM should honour has to be present in that context, either because you wrote it there or because it pulled the material in through a tool.

This is why an edition workflow starts with the documents that describe it. Encoding guidelines, a data model, worked examples and the known failure cases of the OCR engine form the knowledge layer. The agent reads them at the start of a run and works against them instead of against a general idea of what TEI looks like.

Verification closes the loop. Every transformation the agent proposes is checked against facsimile and schema, and the check leaves a trace that a third person can follow.

Sample text, written to demonstrate the switch.

Deutsch

Ein Large Language Model schlägt keine Fakten in einem Speicher nach. Es setzt einen Text unter den Bedingungen fort, die sein Kontext vorgibt. Alles, was das LLM berücksichtigen soll, muss in diesem Kontext vorhanden sein, entweder weil Sie es hineingeschrieben haben oder weil das LLM das Material über ein Tool geholt hat.

Deshalb beginnt ein Editionsworkflow bei den Dokumenten, die ihn beschreiben. Encoding-Guidelines, ein Datenmodell, durchgearbeitete Beispiele und die bekannten Fehlerfälle der OCR-Engine bilden die Wissensschicht. Der Agent liest sie zu Beginn eines Laufs und arbeitet gegen sie statt gegen eine allgemeine Vorstellung davon, wie TEI aussieht.

Die Prüfung schließt den Kreis. Jede Transformation, die der Agent vorschlägt, wird gegen Faksimile und Schema geprüft, und die Prüfung hinterlässt eine Spur, der eine dritte Person folgen kann.

Beispieltext, geschrieben zur Demonstration des Umschalters.
