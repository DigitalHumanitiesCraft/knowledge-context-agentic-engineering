# Example Data (GDA Göttingen 2026)

The exercise of this instance runs on material the participants bring themselves, in four steps documented in `profile.md`. Nothing of it is held in this repository.

Three existing project pipelines carry the instance as case studies rather than as participant data, a music-archival pipeline from spreadsheets into a linked-data model, a library pipeline from scans to TEI, and a static generator for a review journal.

Two data points are undecided. The demo dataset for part one of the demonstration and the change task for part two are not fixed, and the fallback dataset for participants who bring no material of their own is not chosen. The partner institute has to clear the demo state for public display before the demonstration can be shown.
