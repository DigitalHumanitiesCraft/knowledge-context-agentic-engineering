# Example Data (Fachschaft Mittelalterstudien Heidelberg 2026)

The intended example data is documented in `profile.md` and none of it is held in this repository.

The hands-on works on roughly ten charters that share persons or organisations, drawn from a Vienna charter corpus covering 1177 to 1414. The primary proposal is a family holding of 1382 to 1414 with three connecting persons and documented facsimile URLs. The alternative is a chapel holding of 1385 to 1412. Switching the hands-on base to the primary set is a standing operator decision.

Rights state, unresolved and blocking. The licence file of the source corpus names CC BY 4.0 with copyright at the Universität Wien and is marked pending, and the Monasterium image rights are not documented in the source repository. Both need clearing before any distribution to participants, and the hands-on cannot run without the images. The participant data folder must not be published while that gate stands.
