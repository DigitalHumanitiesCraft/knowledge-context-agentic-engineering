# Slide Deck KUG Summer School 2026

The KUG slide deck is a single English presentation covering all four sessions. Its 63 slides were copied from five existing presentations before translation. The source layouts, images, diagrams, citations, typography, and object placement remain in place wherever the English text fits the inherited composition.

## Live presentation

[Open the English KUG slide deck in Google Slides](https://docs.google.com/presentation/d/1m9c6RAUKz_4QTaICfMf11CPmjOY3H-SnFA26UEWkXkU/edit).

The presentation contains 63 slides. All source slides were inspected before selection, every retained slide was visually checked after translation, and the final PPTX passed both the overflow test and the template-fidelity test with zero issues. The native Google Slides import contains all 63 slides. Import-sensitive slides were checked from fresh Google thumbnails and corrected in place. This state is ready for content review; it has not yet received user acceptance.

## Language rule

Every slide shown in the KUG sessions uses English for titles, body text, prompts, instructions, captions, and speaker-facing notes. German source slides are translated during adaptation. Names, titles, transcribed source text, and technical identifiers remain in their source form where scholarly accuracy requires it.
