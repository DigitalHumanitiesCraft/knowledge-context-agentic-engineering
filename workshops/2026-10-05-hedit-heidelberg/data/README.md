# Example Data (HEDIT Heidelberg 2026)

The intended example data is documented in `profile.md` and none of it is held in this repository.

The worked example decided on 2026-08-05 is the letter `o_szd.1079` from Stefan Zweig Digital, whose TEI header carries a CC-BY licence. The pipeline artefacts are held complete in the associated handwriting and optical character recognition pipeline repository, and the facsimiles are obtainable from the GAMS repository. Alongside it stand the synthetic teiCrafter fixtures.

Day 2 runs on material the participants bring themselves, supplied as plaintext, TEI, DOCX or images together with a one-page description.

Rights state. The rights-restricted material of the Zentralbibliothek Zürich is excluded from the shared participant folder and is shown on the projector at most.
